# Regressão Linear: Rádio vs. Vendas

Este projeto realiza uma análise simples de como o investimento em propaganda de rádio influencia o volume de vendas mensais.

##  Sobre o Projeto

O script `regressao_linear_radio.py` utiliza um modelo de Regressão Linear Simples (OLS) para entender a relação entre os gastos com anúncios em rádio e o retorno em vendas. Ele carrega os dados, ajusta o modelo estatístico e gera uma visualização clara dos resultados.

##  Funcionalidades

* **Ajuste do Modelo:** Calcula o intercepto e o coeficiente angular da variável `radio`.
* **Previsões:** Estima as vendas esperadas com base nos valores investidos no rádio.
* **Visualização:** Gera um gráfico de dispersão dos dados observados sobreposto com a reta de regressão linear ajustada.
* **Métricas de Avaliação:** Calcula e exibe o R², o R² ajustado e o Erro Quadrático Médio (MSE) dos resíduos.
